# Changelog

## 0.1.0 - 2026-10-01

- Add a compact iNiR bar quota reading.
- Add an AI Usage card below the left-panel CPU/RAM status rings.
- Read provider data from `ai-usagebar usage --json`.
- Add five-minute polling, local reset countdowns and manual refresh.
- Add repeatable install and uninstall scripts for iNiR 2.31.x.
- Support Linux aarch64 through the upstream `ai-usagebar` release.
